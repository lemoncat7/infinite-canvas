# 全局模型管理

管理员登录后，从画布右上角用户菜单进入 **全局模型**。普通用户只读取模型目录，不能读取连接地址、代理或密钥，也不能修改配置。

## 使用顺序

1. 服务商连接：填写名称、HTTP(S) 接口地址、密钥，可选 HTTP(S) 代理。地址可带 `/v1`；支持管理员配置内网兼容接口。
2. 模型目录：选择连接、协议适配器，填写上游模型 ID 和显示名称。可通过“测试连接 / 获取模型”查询上游 `/v1/models`，也可手填 ID。
3. 按实际能力配置参考图、透明背景、尺寸、分辨率、画幅和时长。空的规格列表表示不额外限制；服务商仍会校验。
4. 默认分配：分别配置图片、视频、提示词助手、漫画对话与规划的默认模型。没有默认模型时需要显式选择；文本助手应配置默认模型。

显示名称支持中文。图片和视频可以配置单次创作点数；文本助手本版不支持按次计费。停用默认模型/连接前需先更换或清空默认分配。暂不提供物理删除，保留旧节点的模型识别。

## 协议范围

- OpenAI 兼容图片：`/v1/images/generations`、`/v1/images/edits`。
- OpenAI 兼容视频：`/v1/videos` 及其查询接口。
- Agnes 图片、视频。
- OpenAI 兼容 Chat Completions：提示词助手和漫画工作流。

“兼容 OpenAI”不保证所有模型的参数完全相同；新协议仍需要独立适配器。TTS、SDCPP 专用协议不在本次页面管理范围内。模型列表发现不自动推断协议、价格或能力，也不直接调用生成接口。实际图片/视频测试需单独确认，可能产生服务商费用，不扣用户创作点数。

## 配置生效与兼容

- 原环境变量显示为只读连接。点击“导入环境配置”后复制到持久配置，之后重启不会覆盖页面修改；不会修改 `.env`。
- 可先新增页面连接和模型，再决定是否导入环境配置。环境与页面同名模型应在菜单中选择具体条目，避免上游 ID 歧义。
- Agnes 环境密钥池随导入保留；密钥留空保存会保留原密钥/池。填写新密钥会将该连接替换为单个新密钥。
- 保存后服务端新请求立即生效。前端进入工作区、重新聚焦窗口及可见页面每 60 秒刷新目录。正在编辑节点时延后重建菜单，避免打断输入。
- 已排队任务保存加密执行快照，继续使用提交时连接、模型和点数。修改配置不会改变旧任务费用，也不会偷偷替换停用的旧节点模型。
- 页面管理模型失败时保持同一模型重试；不再切换硬编码文本备用模型或本地图片备用服务。
- 多管理员同时保存采用版本检查：冲突不会覆盖他人配置，需刷新后核对修改。

## 数据与安全

配置位于 `DATA_DIR/model-config.json`，使用 AES-256-GCM 加密；密钥位于 `DATA_DIR/model-config.key`，Unix 权限必须为 `600`。备份时需要同时保护配置、密钥和原任务数据库；只备份配置无法恢复。密钥丢失/损坏时不会静默替换，需恢复备份。

本应用采用单 API 进程写入配置，与现有 SQL.js 持久化部署约束一致；不支持多个 API 实例同时写同一数据目录。不要把密钥加入 Git 或提供给浏览器。已提交任务需旧密钥快照完成执行，轮换上游密钥前应先处理队列。

## 验证

```sh
npm run build
npm --prefix api run test:models
npm run test:models
npm --prefix api run test:comic
```

模型后端测试使用临时目录和本地模拟上游，不调用真实付费模型；覆盖加密、重启读取、权限、并发配置冲突、参数校验以及实际 API 排队后的模型/密钥/费用快照。
