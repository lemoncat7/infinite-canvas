# 全局模型

管理员从一个页面管理所有连接与模型：顶部用默认卡片和可搜索列表选择模型，下方添加服务商，在该服务商内选择上游模型或手动填写 ID。模型在所属服务商内原位展开编辑，不切换页面或重复选择服务商。

服务商支持最多 32 个 Key，保留已有的轮换、限流和额度冷却机制。已保存的 Key 不回显。每个模型直接配置用途、优先级、点数和协议，详细能力在展开项中设置。上游模型列表不保证所有模型均兼容已有协议。

默认用途可以固定指定模型、手动选择，或使用 `@auto` 自动分配。自动分配只考虑已启用、服务商已启用且用途匹配的模型，优先级数值越小越优先；相同优先级按 ID 排序。不自动重放失败任务或跨模型重试，以免重复计费。固定默认不受其他模型优先级调整影响。关闭固定默认模型的用途前，必须先更换默认。文本模型可分别用于提示词助手、漫画规划或两者。

## 配置来源与升级

- 新安装不从环境变量创建模型。先添加服务商，再添加模型、分配默认用途。
- 不再读取或导入任何环境模型，包括旧版尚未导入的安装。旧导入接口返回 410。
- 配置升级到 `schemaVersion: 2` 前，保存加密原文件到 `model-config.json.before-provider-v2`。只整理已经保存的记录，不读取环境变量：清除旧环境名称前缀，合并地址、代理、Key 集合及启用状态完全相同的旧环境连接，更新所属关系并保留模型 ID、手动修改、默认用途和生成快照。不同凭据或人工命名的服务商不合并。
- 旧模型未指定用途时按类型补全原有用途，升级只执行一次。重启或修改环境变量不会新增或覆盖页面配置。
- 回滚备份需要原 `model-config.key`。备份不包含明文密钥，不能单独替代该密钥文件。
- 已提交生成任务继续使用原来的加密配置快照，不随编辑或迁移更换服务商。
- 代理、存储和服务运行等环境配置不在本次移除范围内。

## Agnes Video 2.5

官方 ID 为 `agnes-video-2.5` 和 `agnes-video-2.5-flash`，不是 `agnes-video-v2.5-flash`。
二者沿用 `/v1/videos` 创建与 `/agnesapi` 查询入口，但不使用旧版的 width/height/num_frames 等字段。

- 使用 text / reference / keyframe 模式，4–12 秒。
- Flash 仅 720P，参考图最多 5 张；普通版最多 8 张。
- 首尾帧模式使用 1–2 张图片。
- 图片宽高均须在 256–5760 像素范围内，每张小于 15 MiB，总计小于 50 MiB。不自动放大原始素材掩盖清晰度问题。
- 新增这两个已知模型时预填官方协议与规格；已有管理员配置不会被自动覆盖。

参考：https://www.agnes-ai.com/zh-Hans/docs/agnes-video-25-flash
# Key 冷却与恢复

- 冷却按接口地址和 Key 隔离；保存不同 Key 不继承旧 Key 的状态，同一个 Key 重复保存不自动解除冷却。
- 模型列表查询与实际生成分别记录冷却，查询接口失败不会锁住生成。
- 401 或明确的无效密钥错误进入认证冷却（默认 5 分钟）；普通 403、模型权限、参数错误及上游无可用认证资源不作为整个 Key 失效的依据。
- 限流和余额不足仍自动轮换可用 Key，保留 Retry-After；网络异常不自动重放，已接受的视频任务不切换 Key。
- 服务商配置中，每个已保存 Key 可点击「重新验证」。仅请求该连接的模型列表，不保存表单、不生成内容；验证标准列表成功才清除对应认证冷却。失败保留原状态；生成额度和限流不会因为能查列表就被清除。
- 验证只使用已保存地址、代理和 Key，禁止携带原密钥到未保存的新地址；同 Key 的验证间隔至少 15 秒，更新中的认证失败不会被较早的验证结果覆盖。
